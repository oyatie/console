PC28 — Fixed participant signatures (design, not Rust implementation)
All fixed functions are compile-time linked owner calls. Conn = borrowed &mut PgConnection for the caller's current Company transaction. Ctx = private CurrentCommandContext described OC28, including exact bound command/Account/Company/registration/schema/fingerprint and optional attempt/work. Return Result<T,OwnerError>; any error aborts caller transaction. OwnerError projects only ErrorProjection, never SQL/debug/body. No function commits, opens a pool, spawns, sends a network request or accepts an executor callback. Only authenticated domain orchestration constructs Ctx. PgConnection lifetime cannot outlive owning transaction.

Aliases are exact schema pointers, not arbitrary JSON:
DraftInput = action-types::SourcePreparationRequest; Prepared = submission24::Preparation24; Sealed = action-types::SealResult; Submitted = types::EvidenceRef (final retained unit, actual evidence digest and encoded size); Metadata = submission24::SubmissionMetadata24; ResultRef = types::OwnerResultRef; Obligation = types::Obligation; UnitRef = types::UnitRef; GateExpected = types::GateExpectation; Consumed = types::GateConsumptionWitness; Receipt = action-types::ReceiptRef; Observation = action-types::ResultObservation. SourceEffect = types::OwnerResultRef restricted to SOURCE_EFFECT, including22/23 exact ordinal/key/event. No caller-supplied digest substitutes for a verified owner output.
Plan = private ProtectionPlan26 with evidence requirements, current semantic fences, query witnesses, lineage refs, reserved late unit identities, and checked materialized/fresh/covered budgets. Constructor only fixed source/native owner extraction over exact decoded prepared input, or fixed common-owner extraction over exact admitted SealedOwnerIntent and its registered decoded common input; every variant carries actual typed selector/unit/obligation rather than SQL/table names. ProtectedPlan is a private one-transaction witness returned after shared/exclusive admissions and current reads; cannot serialize or survive transaction. Adoption = (org_id,adoption_id,result_ref,Submitted,purpose governed revision,Obligation,actual independent pins). Finish = private owner result list plus exact final fingerprint and domain outcome; domain owner constructs only after all result/member correlations pass.

common.prepare_source(Conn,Ctx,DraftInput) -> Prepared
Checks draft/schema/head/custody/exact24 identity and owner input decode; creates real retained preparation unit, immutable source binding and preparation receipt. Idempotent exact preparation; changed binding conflicts.
common.seal_source(Conn,Ctx,action-types::DraftSeal,Option<Prepared>) -> Sealed
Locks exact draft custody/head, reserves actual command+attempt and optional stable gate request perIC28; seals exact source binding once. Only prepared source actions require Prepared; future decision/result digests are absent.
custody.resolve_protection_plan(Conn,Ctx,Plan) -> ProtectedPlan
Applies CP28 ordered lifecycle/current-source protection and exact budgets. Rechecks current suitability separately from evidence retention. Plans include all late reserved units before effects; no undeclared late dependency insertions.
custody.finalize_source_submission(Conn,Ctx,Prepared,Sealed,SourceEffect,Metadata,ProtectedPlan) -> Submitted
Checks22/23 effect row/ordinal and24 actual canonical immutable body; publishes real bytes, hash, size and binding. No caller-produced future source hash. Return matches exact command effect;25 reciprocal publication constraint deferred until owner receipt finalization.
custody.adopt_owner_result(Conn,Ctx,ResultRef,Submitted,purpose:GovernedRevision,Obligation,ProtectedPlan) -> Adoption
Resolves actual immutable owner result before adoption, validates result/Company/purpose/submission and creates exact obligation/pins usingIC28 physical key. Source subtype additionally enforces unique slot1 and reciprocal22/25 source membership; native/common does not forge SourceEffect.
gate.consume_for_owner(Conn,Ctx,GateExpected,Finish) -> Consumed
Loads actual governance request/decision, compares Ctx sealed fingerprint and current policy/validity/distinct human, requires unused exact gate and admitted owner result; inserts one consumption. GateExpected is internal, not part of sealed business body. No gate -> caller does not call participant.
common.finish_owner_attempt(Conn,Ctx,Finish,adoptions:bounded list<Adoption>,Option<Consumed>) -> Receipt
Checks complete required result/adoption membership and optional gate requirement. Appends exact business receipt and audit, finalizes actual attempt/work transition. Direct commands append receipt without fabricated attempt. Final commit remains caller's; deferred checks reject incomplete effect/member/binding. Replay probes precede this whole sequence and return original receipt under current disclosure without new pins/effects.

PreparedNativeInput/Calculation are private payroll-carriers; payroll owns their producer/staging/final activation asIC28. Common source preparation is never mislabeled as the native producer. Internal protection/postcondition helpers may be factored within an owner, but these fixed cross-owner signatures are the admitted borrowed-transaction surface.

common.publish_owner_submission(Conn,Ctx,intent:types::SealedOwnerIntent,registered_input:action-types::RegisteredInput,ProtectedPlan) -> Submitted
For NON-SOURCE actions only, the common draft/attempt owner materializes exact SEALED_OWNER_SUBMISSION28 bytes from its real sealed command/revision and original Actor; no SourceEffect/ordinal/SourcePayloadRef24 is fabricated. Snapshot body is domain tag, schema/codec registration, Company, original Account, exact attempt-or-direct command identity, action/target/expected, stable optional gate request, and exact sealed normalized business bytes. Byte encoding is CCF1/action30-v1 plus length-delimited exact body, with explicit8MiB bound only for registered publication targets; all ordinary limits remain. Reserve a retained unit identified by Company+command+submission kind before effect, then fill actual bytes/digest/size and bind to common seal receipt under same transaction. Return EvidenceRef only after immutable bytes exist and identity/correlation check passes. Native prepared semantic/custody manifests are separate retained evidence, not substituted for original intent. Direct commands persist their original normalized input under common command custody without fabricated FD1 attempt.
For SOURCE actions, finalize_source_submission remains the specialized producer of actual24 final submission bytes and EvidenceRef; its input SourcePayloadRef24, preparation digest and eventual snapshot digest remain distinct. adopt_owner_result accepts final EvidenceRef for either producer, validates unit's closed selector kind, origin command and actual immutable snapshot;25 mandatory source slot1 additionally requires SOURCE_SUBMISSION24 with exact22/23/24 correlation. Non-source snapshot selectors use OWNER_SUBMISSION identity below, not SOURCE_INPUT24. This shared publisher is an internal common-owner participant, never an alternate public source writer.

common.admit_direct_intent(Conn,Ctx,registered_input:action-types::RegisteredInput) -> types::DirectIntentWitness
Only registrations explicitly admitted for direct execution may enter. Under original Company command receipt-first reservation, verify exact Account/context/action/schema/target and normalize the complete input/expected fields. Reuse common command custody row keyed(org_id,command_id) to persist immutable normalized input bytes/digest and fingerprint before any business effect; existing equal bytes replay admission, changed bytes/actor conflict. No final receipt, attempt, future snapshot hash or domain result is required to reserve an intent. Successful receipt replay returns before this constructor. A preparation command may persist this same reservation across its durable BUILDING stage; later finalizer reloads and revalidates actual custody row plus current authority before privately reconstructing the witness. It cannot adopt another actor's direct command.
SealedOwnerIntent is owner-private ATTEMPT(actual SealResult) or DIRECT(actual DirectIntentWitness). Generic publisher validates either against Ctx and current stored immutable custody, never trusts deserialized proof. ATTEMPT requires exact sealed revision/attempt; DIRECT requires exact reserved command/input row and admitted direct route, no FD1 fields. Both publish the same origin-command-bound OWNER_SUBMISSION evidence without changing fingerprint. Source24 specialized finalize still requires actual source preparation/seal/attempt and cannot use DIRECT to bypass that protocol. Group control commands retain their separate Group receipts and do not enter this Company publisher.

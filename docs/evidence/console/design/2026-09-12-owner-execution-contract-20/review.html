실행 책임을 하나로 연결

기존 Rust 계산과 Cedar 검사를 재사용하고, 제한된 소유자 저장 진입점이 업무 결과·결재 소비·자료 보존 연결·영수증을 같은 트랜잭션에 기록합니다. 중간 실패면 함께 취소하고, 응답을 잃으면 같은 명령의 영수증으로 확인합니다.

기존 함수를 연결만 공유한다고 호출할 수 있는 것은 아닙니다. 자체 연결을 여는 함수, 일반 쓰기 권한을 요구하는 함수, 앱의 직접 SQL, 역순으로 잠금을 잡는 경로를 식별했습니다.

화면에서는 필요한 입력만

자동화와 수동 수정 모두 같은 객체와 액션을 사용합니다. 큰 원천 자료는 확인된 수정본을 참조하고, 일별 계획 변경은 정해진 입력 항목만 전송합니다. 업로드 성공과 실제 업무 확정을 구별하며 부족한 자료는 원래 객체의 보완 경로로 연결합니다.

Verus 검증 후보

공식 자료와 현재 Rust 계산 코드를 대조했습니다. 기존 실행 코드의 정수 절사·반올림·변환 및 호출 범위를 먼저 증명하는 방안을 조건부 추천합니다. 증명용 계산기를 따로 만들거나 검증하지 않은 DB·Cedar·저장소를 가정으로 감싸 전체가 검증됐다고 하지 않습니다.

Verus 실행·증명 완료 주장은 없습니다. 도구 호환성·검증 범위·명시적 가정·유지비를 확인한 후 도입합니다. Rust1.98.1 고정은 별도로 사용자가 승인한 설정 변경입니다.

남은 구현 전 공백

이번 계약은 실행 소유자와 신뢰 경계를 선택합니다. 전체 SQL 함수·트리거·외래키와 실제 자격·원천·보존·복구·배포 환경은 아직 닫히지 않았습니다. 전체 설계 4회 독립 검토와 SHA 승인, 테스트 후보 검토·승인 전에 업무 구현을 시작하지 않습니다.

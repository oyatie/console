## URL and secret constraints

Generated CI passwords are hex; dev defaults are safe ASCII. User-configured password overrides may contain `@:/?#%+` and must be encoded as password components. Existing `commandDatabaseUrl` simply interpolates raw password; if reused for auth, either correct that existing helper with focused reserved-character tests, or use native URL component setters at the same helper boundary. Do not manually concatenate an unescaped custom auth password and accidentally connect as a different effective identity. Respect AC04 whitelist: no host/dbname/options query overrides and no inherited PGOPTIONS. App URL carries a secret, so neither successful wiring nor refusal may echo it.

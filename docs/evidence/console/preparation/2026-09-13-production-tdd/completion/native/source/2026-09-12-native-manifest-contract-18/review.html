급여 입력·계산 이력의 정확한 연결

기존 급여 소유자와 공통 객체를 재사용하는 설계 후보입니다. 실제 SQL 적용이나 구현 승인이 아닙니다.

상황남기는 기록과 다음 행동
필수 자료가 빠진 입력 준비직원별 막힌 이유와 입력 스냅샷을 보존합니다. 마감·계산은 진행하지 않습니다.
유효하게 마감했지만 계산 결과가 모두 처리 불가계산 시도와 직원별 결과를 남깁니다. 가짜 금액을 만들지 않습니다.
다른 직원의 근태 변경현재 자료를 다시 확인하되, 변경되지 않은 직원의 검토 근거까지 단순 버전 차이로 무효화하지 않습니다.

기존 법인·실행·줄·직원 연결을 강화하고, 같은 날짜의 임금 정정과 원본 참조0을 명확히 했습니다. 공통 엔진 전체나 모든 원천 데이터 계약의 완료를 뜻하지 않습니다. 남은 항목은 readiness.json에 기록했습니다.

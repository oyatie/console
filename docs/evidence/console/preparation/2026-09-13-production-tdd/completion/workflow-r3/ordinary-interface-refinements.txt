# R3 ordinary owner interface refinements

These are proposed source integration shapes in existing owners, not successful implementation evidence, test-only endpoints, new action registrations, or permission constructors. Base fd94667fb9133f1ecb55831f43192bdc46776dc0; parent root approved PA1.2 exact-resource policy use. Missing registration, schema, current authority, source, or field identities fail rather than return fabricated refs.

- `identity::PolicyScope::ExactResource { resource: ObjectRef, schema: GovernedRevision }` is an assignment scope at the existing identity grant owner. ObjectRef is the existing closed org/type/object locator, loaded from the registered owner. No ObjectKey variant is added. Schema/type identity is immutable and same-Company. PolicyScope::Company and ExactResource use the same normal CompanyGrantPlan publisher, Cedar validation, delegated ceiling, current expected head, borrowed catalog writer, authority guard and audit/receipt path. No evaluator-as-user or grant bypass.
- `payroll::read_publication_policy_resource(pool, currentCompanyContext, actual PublicationTarget, actual projection)` returns `{ object: ObjectRef, schema: GovernedRevision, required_fields: Vec<PropertyRef> }`. It looks up the actual native source row and registered policy projection for that historical subject/result/completion, including retained provenance. The primary key belongs to its actual registered projected owner. It never converts ResultRef to another owner's ObjectKey or creates a new projected object.
- `CompanyPolicySchema::actions_for_publication_release()` returns the existing exact registered business/control/read ActionRefs needed for publication; it is schema enumeration, not authorization. `read_field_group_members`, `read_field_group_head`, and `publish_field_group(PublishFieldGroup {command_id,org_id,key,expected,fields,reason})` reuse PA1.2 normal immutable governed property groups and current authority publication. Returned revision must be owner-issued. Empty field groups are a normal explicit no-property disclosure set when valid in the registered schema, not an implicit wildcard. Unknown/mismatched fields are rejected.
- The same-Company test removes the reviewer's broad actual assignments via ordinary revoke. Company control grant excludes every required source field. First exact resource has full registered projection; second exact resource lacks one actual required field. Complete grant tuples are evaluated separately; Company control fields cannot cross-multiply with another resource's source fields. The positive first-only release occurs under identical current grants after atomic refusal.
- `workflow::read_case_work_binding(pool,currentContext,actual TaskRef)` is an authorized fixed read of actual case/task binding; it returns real case_id, not a seeded task or assumed UUID. Raw assertions map public case_id to storage request_id.
- `group::read_original_group_create_input(pool,currentGroupContext,actual GroupOperationRef)` reads the original retained immutable create input under current Group disclosure. It does not reconstruct guessed membership incarnations or expose Company payload.
- `group::read_group_operation` retains GN16 authorized per-Company receipt-derived observation; its bounded lookup failure is UNKNOWN, never no effect. Parent stop does not acquire Company child/task/domain locks. Unknown source probes use real disposable-database lock faults and normal receipt reconciliation.

Native dependency: `two_subject_producer::build_two_supported_deployment(PgPool,scenario)` uses actual two-member supported payroll scope, common qualified profile, independently retained source evidence and actual completion in one Company. Native source owner is responsible for re-signing first-subject profile-bound evidence and freezing accepted bytes.

# Bounded operator finalizer JIT contract

Independent design review; repository sole writer remains root. Lenses: Red Team, Operability, Blast radius, Zero trust. The retained unchanged malformed-helper test failed once at the60-second outer statement budget, then passed in259.01seconds total. Read-only measurements show the prospective metadata query crosses default JIT cost100000 (cost116737.48), with3361.354ms execution including3283.653ms JIT versus59.878ms with JIT disabled. Historical query cost81315.84 remains below threshold. This supports eliminating avoidable operator code generation; it does not prove JIT alone caused the prior timeout.

Approved implementation shape after actual admission:
- Append fixed `-c jit=off` to the existing scrubbed production wrapper PGOPTIONS before psql connects. Keep search_path,60000ms statement timeout,5000ms lock timeout,verify-full TLS,identity checks,one transaction and credential isolation exact.
- Set `SET LOCAL jit=off` in the existing audit_account_transition::operator transaction helper so retained operator regressions exercise the same execution setting as production. Do not alter any assertion, timeout, SQL body, serializer, command bytes or fingerprints. Existing ordinary test-support finalizers already disable JIT.
- No global server/role/database JIT setting, startup mutation, generator change or historical resealing. Only the one-shot operator process and matching test transaction change.

Pre-mortem: test-only tuning could conceal slow production; observing an outer shell environment could miss env-i override; session-wide jitoff could leak into business traffic; a timeout increase could hide continued unbounded work. Detection: actual psql child and transaction settings, rollback scope, immutable SQL hashes, retained original failures. Rollback: revert only two runtime-setting edits; discard isolated test databases using existing owned cleanup. Stop on stale source, missing TLS/real owner, changed history/fingerprint/SQL, increased budgets, incomplete transport evidence or leaked credentials. This is a finalizer-operability prerequisite, not a workload or release qualification.
